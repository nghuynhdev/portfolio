# AI for Devs cover images

Current generation: **v2**, created with the built-in `image_gen` tool in nine sequential batches of three article covers. All 27 Vietnamese articles and their English translations were read in full before their respective prompts were written.

Final assets are 1600 × 900 WebP. Each language explicitly selects the same Vietnamese-basename `-v2.webp` file through frontmatter, avoiding stale image-cache URLs. Old unversioned cover files were removed after replacement. Per-article social JPEGs and index mosaics are regenerated from the new covers.

## Prompts and review evidence

- [BRIEFS-v2.json](./BRIEFS-v2.json): article paths and content fingerprints, section-by-section coverage, main message, alternative concepts, chosen treatment, technical caveats, exact generation/edit prompts and review notes.
- [PROMPTS.json](./PROMPTS.json): active asset paths and generation sources.
- [posts/PROMPTS.md](../posts/PROMPTS.md): the five general-blog covers handled separately.

## Visual direction

The collection varies its visual language instead of repeating one navy/cyan/amber template: token-typesetting press, prompt drafting blueprint, browser response ribbon, source archive, tool workshop, cache switchyard, evaluation inspection, offline laptop, permission boundary, protocol hub, hybrid-search sorter and finite context case.

Later articles use an idempotent dispatch ledger, release console, source-linked document fields, adapter calibration, diff behavior checks, task-matched skill cards, UI artboard, SEO evidence board, serial/parallel schematic, browser journey, stale-response experiment, scoped rules archive, skill binder, independent runtime permissions and exploded plugin kit.

These are conceptual illustrations, not actual product screenshots, portfolio analytics or benchmarks. Both full-resolution results and 320 × 180 thumbnails were inspected. The fine-tuning and React timing images received targeted edits to remove excessive English copy and improve clarity.

Each cover was decoded and captured in the running site at desktop width 1440 and mobile width 390 for Vietnamese, and mobile width 390 for English. Paginated series listings were checked for the corresponding new asset. Per-article observations are in the brief manifest.
